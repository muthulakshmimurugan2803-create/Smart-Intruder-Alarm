# Smart-Intruder-Alarm
Smart Intruder Alarm using ESP8266 NodeMCU and RFID RC522. This project identifies authorized and unauthorized RFID cards and provides visual and audible alerts using LEDs and a buzzer. It is designed as an IoT-based security prototype using Arduino IDE and Blynk IoT for monitoring and notifications.
